# 健康检查验收清单

本次改动只处理健康检查及其共用日志判定，不涉及 Map。

## 自动验证

```powershell
npm test
npm run lint
npm run build
node scripts/verify-health-core.mjs
cargo test --locked --no-run
```

`verify-health-core.mjs` 直接编译并执行生产代码中的文件检查和备份修复测试，不依赖 Tauri。它覆盖重复/失效地景注册、空导航文件、损坏插件文件、修复范围、备份恢复、保留新配置、失败回滚、中断恢复和篡改备份路径。

Windows 的 Tauri Rust 测试程序可能在进入测试框架前以 `0xc0000139 / STATUS_ENTRYPOINT_NOT_FOUND` 退出。`cargo test --no-run` 只能证明测试编译和链接成功；不能代替实际运行。

## 需要手工执行的场景

通过 `npm run tauri:dev` 启动桌面程序，选择有效的 X-Plane 安装。修改样本文件的场景请使用安装副本，避免干扰实际飞行配置。

| 场景 | 操作 | 预期结果 |
| --- | --- | --- |
| 日志结尾不完整 | 用以普通插件初始化信息结尾、没有退出或崩溃标记的 `Log.txt` 执行快速检查 | 上次会话显示“信息”，明确表示无法确认结束方式；不得显示意外关闭，不启动崩溃转储分析 |
| 正常退出与明确崩溃 | 分别使用包含 `X-Plane has shut down` 和 `This application has crashed` 标记的样本日志 | 前者通过；后者显示明确崩溃标记和对应证据，但不凭日志结尾猜测根因 |
| 正在运行 | X-Plane 运行时检查，再尝试修复和恢复 | 不判断当前会话已结束；禁止更改文件。检查后才启动 X-Plane 时，同样在修复前被拦截 |
| 英文报告 | 界面分别切换中文、英文及另一种语言，各导出 Markdown 和 JSON | 报告标题、检查名称、说明和建议均为英文；原始文件名和日志证据保留原文 |
| 默认脱敏 | 报告中包含用户名、带空格的用户目录、安装目录、外接盘和网络共享路径 | 用户名、安装根目录和共享地址被替换；错误码、时间戳、DLL/插件名、地景名、相对路径及日志上下文保留。不得整条替换为 `PRIVATE_EVIDENCE` |
| 原始路径开关 | 确认“包含原始路径”后导出，再切换历史报告 | 第一次包含原始路径；切换报告后重新默认脱敏 |
| Gateway 无安装 | 没有由 Gateway 管理的已安装机场时执行完整诊断 | 显示不适用，不显示“有更新”的描述或更新操作 |
| Gateway 查询 | 有已安装机场时分别联网和断网执行完整诊断 | 有明确的安装数、完成查询数和更新数；有更新时提供机场及提交编号证据。查询失败显示无法检查，部分失败不能被当作全部通过 |
| 地景注册 | 在副本中增加重复启用条目、失效启用路径和失效链接，并保留一个失效但已禁用的条目 | 前三项分别给出文件/路径或行号；已禁用的缺失目录不产生“已启用路径失效”警告 |
| 深度检查 | 在副本中加入零字节 `Custom Data/earth_nav.dat` 和一个空的当前平台插件文件 | 完整诊断分别报告空导航数据和插件二进制问题；其他平台的插件文件不被当作当前平台损坏 |
| 读取失败 | 令测试目录中部分文件不可读，或使用超过扫描上限的测试集 | 明确显示无法完整检查及错误/上限；不得用“通过”掩盖未读取的文件 |
| ReShade 残留 | 仅保留 `ReShade.ini` 或 `reshade-shaders`；再在副本中加入代理 DLL | 只有残留配置时不判为注入 DLL；有配套 DLL 时给出具体文件，并提供确认后停用 |
| 停用注入 DLL | 在测试副本中确认停用，再从“修复与备份”恢复 | 只移动识别出的代理 DLL；其他 DLL、着色器和配置保留；恢复后原 DLL 字节不变 |
| 重建着色器缓存 | 确认重建，启动一次 X-Plane 生成新缓存，再关闭并恢复旧备份 | 原缓存可恢复；后来生成的缓存另存为可恢复备份。下次加载可能因缓存重建而变慢 |
| 重置首选项 | 先记录画面和摇杆配置，再确认重置，启动并关闭 X-Plane，最后恢复 | 确认框明确包含控制/摇杆分配影响；默认配置可生成；旧配置能恢复，新配置另外保留。备份位于安装目录的 `.xfast-health-backups` |
| 地景一键修复 | 执行排序、启用默认机场或创建缺失注册文件的操作 | `scenery_packs.ini` 实际写入；完成后重新检查相关项目。仅修改索引不算成功 |
| 页面操作 | 搜索检查名称或证据，切换“全部/问题”，在深浅主题和不同窗口宽度下选择条目 | 结果与详情对应、无横向溢出；证据默认折叠，点击后展开，切换检查项或报告后重新折叠；字号可读；并排时两栏底边始终对齐，长证据和展开的修复/历史/导出区域在右栏内滚动，不撑高整个页面；窗口缩小或调整系统缩放后仍不溢出，窄窗口自动上下布局；不再出现只弹一句通用提示的“查看处理建议”按钮 |
| 历史及切换安装 | 选中历史报告或切换另一个安装，再尝试修复/恢复 | 历史结果只读；不得使用上个安装的诊断或备份执行操作 |

离线、没有可用转储、没有机场或没有插件的环境，只能验证相应的不可用/不适用分支；其余分支需要对应样本或真实环境。
