# 地景自动排序开关验收

请使用测试用 X-Plane 安装或地景目录副本，先备份 `Custom Scenery/scenery_packs.ini`。

1. 关闭设置中的“地景自动排序”，进入管理页面。地景标签仍可打开；搜索、分类、依赖及冲突查看、启停、删除、更新和机场平整功能仍可用，自动排序按钮不显示。
2. 手动拖拽地景、使用上移和下移，再点击应用。文件顺序应采用手动结果；关闭后重开页面及软件，结果保持不变。重置未应用的修改应恢复原顺序。
3. 准备一个刻意不按分类排序的文件，例如网格在机场之前，并保留启用、禁用项与注释。打开页面、刷新、扫描或重建索引，不应改变文件顺序和开关状态。
4. 只切换一个地景的启停状态并应用，应只改变对应的启停状态；其他条目的先后顺序保持不变，不能按页面分类分组的顺序自动重排。
5. 安装新地景、替换现有地景、更新 Gateway 地景，检查原有条目的相对顺序不变。未注册的新地景可由 X-Plane 登记，或在地景管理中同步到文件末尾；不能触发全局分类排序。安装过程中关闭开关，完成时也不能自动排序。
6. 删除一个地景，仅移除它的文件注册，其他条目及注释保持原样。外部链接地景应按实际路径识别，不能错误删除其他注册。
7. 应用仅改变地景启停状态的预设，确认顺序保持不变。运行健康检查，关闭自动排序时不提供自动重排修复；其他修复仍可使用，且不改变现有顺序。
8. 重新开启自动排序，应重新显示自动排序按钮，确认手动触发及安装后的自动排序恢复正常。再关闭并重启软件，确认该设置仍被遵守。

明暗主题及中英文界面各检查一次。对比文件时，忽略主动执行的启停修改和新增/删除项；其余已有地景的相对顺序必须保持。
