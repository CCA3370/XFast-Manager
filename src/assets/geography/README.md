# Flight plan basemap

Natural Earth 1:110m admin-0 country polygons, public domain.
Source: https://github.com/nvkelso/natural-earth-vector/blob/master/geojson/ne_110m_admin_0_countries.geojson
Terms: https://www.naturalearthdata.com/about/terms-of-use/

Properties reduced to English names; coordinates rounded to four decimal places.
This bundled geographic overview works offline. It is not a street or navigation chart.
